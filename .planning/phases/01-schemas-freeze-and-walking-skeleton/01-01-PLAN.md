    - A function parameter with an explicit `number` type annotation whose name ends in one of those five suffixes is reported
    - An identifier named `rateLimit`, `capacity` or `feedback` is NOT reported — the suffix anchors at end-of-identifier

Add a config object whose `files` glob is exactly `['packages/engine/**/*.ts', 'packages/schemas/**/*.ts']` and whose `rules` carry a `no-restricted-syntax` entry with three AST-selector objects, as set out in the research: one over `TSPropertySignature`, one over `VariableDeclarator`, one over function parameters, each matching `Identifier`/key name against `/(amount|total|rate|fee|cap)$/i` with a child `TSTypeAnnotation > TSNumberKeyword`, each carrying the message `Money-named identifiers must use the branded Minor type, not number.`
