<objective>
Prove PRD §10.7's table end to end, row by row, and close the phase.

Most of §10.7 was built in earlier phases — the intake blocks in Phase 5, the recompute banner
in Phase 6, the engine-error rollback in Phase 4 — and this phase's own boundary makes proving
them, not rebuilding them, DISC-06's job. What makes that worth a plan of its own is the failure
mode it guards against: a table of seven specified behaviours, spread across five phases, with
no single place that asserts all seven still hold together. A row that quietly stopped behaving
as specified would be invisible until someone hit it.

Purpose: one file that reads like §10.7 itself, so a reader can check the table against the
tests line for line, and so the one row that cannot be exercised yet is visible as a recorded
gap rather than as an absence.

Output: a row-per-row edge-state suite, a full-suite regression confirmation, and the phase's
planning records closed honestly.
</objective>
