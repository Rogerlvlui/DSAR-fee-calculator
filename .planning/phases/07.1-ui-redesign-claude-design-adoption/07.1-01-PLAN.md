<objective>
Adopt the Claude Design export's typography and corrected verdict-colour mapping across the three
already-built PRD §10 screens whose visual system the export actually matches (Legal review, HR
intake, HR result/notice), per D-1. This is Wave 1 of the phase's two waves: if time runs out after
this plan, the restyle alone is a coherent, demoable improvement with no dependency on the Audit
trail work in Plan 02.

`07.1-UI-SPEC.md`'s headline finding is that the colour palette is already byte-identical to this
export — the real work is typography (three named webfonts, self-hosted, not the current system
stack) and markup/structure (numbered-step intake sections, left-accent-bar review cards, a
letter-styled notice document), plus one genuine colour correction (DISALLOW was wrongly mapped to
the destructive red; it belongs on the neutral Deny grey).

Purpose: match the approved design contract's visual result without reinterpreting it through
Tailwind utility classes, and without regressing any of the four already-passing phases' tests
(D-4).

Output: self-hosted Newsreader/IBM Plex Sans/IBM Plex Mono wired through next/font/google into the
existing token file, the corrected verdict-colour mapping, and three restyled screens.
</objective>
