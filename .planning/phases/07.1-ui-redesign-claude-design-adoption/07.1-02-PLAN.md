<objective>
Add the new Audit trail screen (D-2) — a read-only, whole-log view for the `DPO_ADMIN` role — as
Wave 2 of this phase, depending on Wave 1's font/token work so the new screen inherits the same
typography rather than being styled twice. If Wave 1 alone shipped, this plan is the optional
stretch; if it also lands, the phase closes with all five ROADMAP success criteria met.

The design export's fourth screen shows "Audit trail" with a per-matter scenario view and a "Hash"
column implying real event-chaining. Neither exists in `packages/audit` today (append-only, not
hashed), and `exportAuditLog()` — the only capability that exists — returns the whole log, not one
matter's slice. This plan builds the honest version: a global two-stream view with a Matter column
added structurally beyond the design's own markup, and Pack/Engine columns standing in for the
Hash column the system cannot yet back with real data (D-3).

Purpose: give the DPO/audit role the whole-log visibility AUDIT-04 already built the capability for,
without ever implying a guarantee (event-chain integrity) the system does not provide.

Output: `/admin/audit`, gated to `DPO_ADMIN`, rendering both real event streams end to end.
</objective>
