## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 1 - Bug] Next's page-export type checker rejects `AUDIT_TRAIL_RESTRICTED_MESSAGE` as a named export from `page.tsx`**
- **Found during:** Task 3, running `pnpm --filter @dsar/web exec next build --webpack` as the phase-closing regression sweep's final gate
- **Issue:** `next build`'s generated `.next/types/app/admin/audit/page.ts` type-checks a `page.tsx` module against a closed set of framework-known export names (`default`, `metadata`, `config`, `generateMetadata`, ...). The Task 1 implementation exported `AUDIT_TRAIL_RESTRICTED_MESSAGE` as a plain named constant from `page.tsx`, which failed the build's TypeScript pass with `TS2344`. `pnpm test`, `pnpm run typecheck` and `pnpm run lint` all stayed green throughout — this failure mode is specific to `next build`'s own generated route-type file, which none of the other three gates run.
- **Fix:** Relocated the constant into `apps/web/src/ui/admin/audit-trail-view.tsx`, alongside its sibling Copywriting Contract constants (`AUDIT_TRAIL_EMPTY_HEADING`/`_BODY`); `page.tsx` now imports it rather than declaring it. A direct grep confirmed no other `page.tsx` in this codebase makes this mistake.
- **Files modified:** `apps/web/app/admin/audit/page.tsx`, `apps/web/src/ui/admin/audit-trail-view.tsx`
- **Verification:** `pnpm --filter @dsar/web exec next build --webpack` succeeds end to end, `/admin/audit` listed as a real dynamic route in the build output; full suite stayed at 1095/1095; typecheck/lint/depcruise all clean.
- **Committed in:** `8ee2ae9`
