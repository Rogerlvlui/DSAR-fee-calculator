- **Committed in:** `c425476`

**2. [Rule 3 - Blocking] `@dsar/rulepacks/validate` does not resolve from a repo-root-level test file**
- **Found during:** Task 2, first run of `tests/routes/honesty.test.ts`
- **Issue:** `findBannedWord` needed to be imported directly into a test file physically located at `tests/routes/` (not under `apps/web/`), and Node's module resolution walking up from that location never reaches `apps/web/node_modules/@dsar/rulepacks`'s symlink — only `apps/web`-located files (like `assessments.ts`, which already imports `@dsar/rulepacks/stale` successfully) get that resolution for free.
- **Fix:** Added `"@dsar/rulepacks": "workspace:*"` to the root `package.json` (matching the existing `@dsar/schemas` root-dependency precedent) and ran `pnpm install` to link it.
- **Files modified:** `package.json`, `pnpm-lock.yaml`
- **Verification:** `pnpm vitest run --project routes -t "HONESTY"` — 3/3 pass.
- **Committed in:** `ec267dd`

**3. [Rule 3 - Blocking] Rendering a real `.tsx` server component from a `tests/routes/*.test.ts` file needs both a tsconfig include and a Vite JSX transform**
- **Found during:** Task 2
- **Issue:** `tests/routes/honesty.test.ts` renders `apps/web/app/layout.tsx` directly (in the node environment, to avoid tripping `server-only.ts`'s `window` guard under jsdom — see key-decisions). Two failures in sequence: `tsc --build` would have rejected the import as outside `tests/tsconfig.json`'s narrow include list (the same TS6307 class of issue 03.1-01/02/03 each hit once), and Vite's transform failed on the untransformed JSX inside `layout.tsx` (`apps/web/tsconfig.json`'s Next-required `"preserve"` JSX mode).
- **Fix:** Widened `tests/tsconfig.json`'s `include` to cover `apps/web/app/layout.tsx`, `apps/web/src/ui/chrome/app-header.tsx` and `demo-banner.tsx`; added the same `oxc.jsx: { runtime: "automatic", importSource: "react" }` option to `vitest.config.ts`'s "routes" project that "web"/"boundary" already carry.
- **Files modified:** `tests/tsconfig.json`, `vitest.config.ts`
- **Verification:** `pnpm run typecheck` exits 0; `pnpm vitest run --project routes -t "HONESTY"` renders the layout successfully.
- **Committed in:** `ec267dd`
