| **Estimated runtime** | ~10s (existing suite) + new web/route tests |

---

## Sampling Rate

- **After every task commit:** Run the relevant project filter (`--project web` or `--project routes`, scoped by `-t` to the task's feature name)
- **After every plan wave:** Run `pnpm test` (full monorepo suite — catches regressions in `packages/engine`/`packages/rulepacks` from a wiring mistake)
- **Before `/gsd-verify-work`:** Full suite must be green
- **Max feedback latency:** 30 seconds
