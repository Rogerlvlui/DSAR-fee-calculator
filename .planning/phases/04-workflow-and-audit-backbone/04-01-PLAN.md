<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP route → data layer | Untrusted request body and cookie-borne role cross here; the role check is the first statement of every data-layer function |
| data layer → workflow guard | The only place a status change is decided; a call site that decides for itself has escaped the boundary |
| data layer → audit writer | A write that is dropped, swallowed or best-effort converts a defensible record into an undetectable gap |
| caller → audit store | Handing out a live reference to a stored event makes an append-only store editable by accident |
| payload construction → frozen payload schema | The one validation point standing between a five-key declared set and a table that cannot be deleted from |
