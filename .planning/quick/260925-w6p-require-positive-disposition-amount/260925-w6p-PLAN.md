# Quick task: refuse a zero or empty amount on Allow / Allow anyway / Reduce

**Why:** During demo rehearsal, clicking "Allow SGD" on a flagged line with the amount box
empty committed the line as "Allowed by you" at SGD 0.00. Cause: `majorToMinor` in
`disposition-controls.tsx` mapped an empty/unreadable box to 0, and `dispositionLine` accepted
0 for REDUCE, ALLOW_WITH_AMOUNT and ALLOW_ANYWAY. The record then reads as an allowance when
nothing was allowed.

**Decision (product owner, 2026-09-25 — PRD §6.3 is silent on a zero amount):** an allowance
or reduction must be above zero. Charging nothing is recorded as Strike (or Accept on a
DISALLOW line, whose engine amount is already zero). Asked because it's a record-keeping /
legal-judgement point, per CLAUDE.md.

**Task 1.** `domain/disposition-actions.ts`: shared `ACTIONS_TAKING_AMOUNT` and
`nothingChargedAction(action)`.

**Task 2.** Server: `requirePositiveAmount` in `dispositionLine` — missing amount or ≤0 /
non-integer → `ValidationError` (400) naming Strike/Accept.

**Task 3.** UI: `majorToMinor` returns `null` for an unreadable box; the amount-taking button is
disabled until the amount is > 0, with a visible text hint linked via `aria-describedby`.

**Verify:** component + route tests; typecheck, test, lint, depcruise; live browser check.
